# R021: Enforcement Policy

oh-my-customcode uses an advisory-first enforcement model. Most rules are enforced through prompt engineering rather than hard-blocking hooks, preserving agent flexibility while maintaining behavioral standards.

## Overview

Hard-blocking hooks are reserved for critical safety boundaries. The majority of MUST rules are enforced through PostToolUse advisory hooks, PostCompact re-injection, and CLAUDE.md prompt guidance. This prevents agents from getting trapped in unrecoverable states while still maintaining standards.

## Priority

**MUST** — The enforcement policy itself defines how all other rules are enforced.

## Key Requirements

**Enforcement tiers:**

| Tier | Mechanism | Rules | Behavior |
|------|-----------|-------|----------|
| Hard Block | PreToolUse hook, exit 2 | stage-blocker, dev-server tmux, rule-deletion-guard | Prevents tool execution |
| Soft Block | Stop hook prompt | [[r011]] session-end saves | Auto-performs then approves |
| Conversation Block | PostToolUse hook + `continueOnBlock` (CC v2.1.139+), exit 2 | stuck-detector, context-budget-advisor, cost-cap-advisor | Feeds rejection reason back into the conversation — Claude continues the turn aware of why the action was blocked |
| Advisory (proactive) | UserPromptSubmit hook | [[r007]], [[r008]] — `r007-r008-drift-advisor.sh` (#1229) | Reads last assistant turn, emits stderr advisory before next response if identification header/prefix absent |
| Advisory | PostToolUse hooks | [[r007]], [[r008]], [[r009]], [[r010]], [[r018]] | Warns via stderr, never blocks |
| Prompt-based | CLAUDE.md + rules/ + PostCompact | All MUST rules | Behavioral guidance in context |

**CC v2.1.163+:** Stop and SubagentStop hooks can return `hookSpecificOutput.additionalContext` (JSON) to feed structured feedback back into Claude's context without triggering a hook error label — enables advisory-style enforcement via Stop/SubagentStop hooks to pass richer context without disrupting turn continuation.

**CC v2.1.199+:** Fixed SessionStart/Setup/SubagentStart hooks silently swallowing stderr when exiting with code 2 — errors are now surfaced. Strengthens observability for the Hard Block/Advisory tiers in the table above (cf. the v2.1.163 `additionalContext` structured feedback note).

**CC v2.1.210+:** Fixed hook callback timeouts being misreported to the model as a user rejection, which had caused unattended sessions to stall waiting on a phantom denial. Since R021 advisory hooks fire every turn and long-running unattended loops (e.g. `/fsd`) depend on them, a hook timeout no longer aborts an unattended session.

**CC v2.1.211/212/214+:** Three platform fixes make hook enforcement decisions reliable in auto/unattended mode: (211) auto mode no longer overrides a PreToolUse hook's `ask` decision on unsandboxed Bash — the `ask` now floors to at least a minimal prompt; (212) `continue:false` hook halts are no longer dropped on tool failure or mid-completion, and hook infrastructure errors are no longer misreported as user rejections; (214) `exit 2` now reliably blocks even when hook stdout JSON fails schema validation. All three strengthen the Hard Block and Conversation Block tiers above (`stage-blocker`, `rule-deletion-guard`, `stuck-detector`), extending the v2.1.210 phantom-rejection fix.

**Why advisory-first:**
1. Hard blocks can trap agents in unrecoverable states
2. Missing dependencies (jq, etc.) don't break the session
3. External skills and internal rules can coexist
4. PostCompact re-injection maintains rules after context compaction

**Hard-block promotion conditions:**

| Rule | Status |
|------|--------|
| [[r010]] | Candidate — orchestrator-direct-write violations > 3/session |
| [[r007]]/[[r008]] | Advisory implemented (#1229 proactive UserPromptSubmit + #1190 retroactive Stop-hook); hard-block variant still candidate if advisory insufficient (#1096) |

**Two-layer R007/R008 drift detection (as of #1229):**
- **Proactive** (#1229): `r007-r008-drift-advisor.sh` UserPromptSubmit hook — fires before each response, catches missing headers early
- **Retroactive** (#1190): `session-reflection.sh` Stop hook — analyzes full transcript at session end

**Promoted to hard block:**
- `rule-deletion-guard.sh` (2026-04-08) — prevents accidental bulk deletion of rule files
